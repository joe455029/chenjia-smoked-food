陳家糖燻滷味 PWA V2.4
======================

V2.1 修正：
- 新增「庫存計算起始日」
- 起始日前的歷史訂單不再扣除目前庫存
- 起始日前的進貨也不納入目前庫存
- 若尚未設定，會以既有最早一筆進貨日期作為起始日；沒有進貨則以當天為起始日
- 庫存異動紀錄依進貨日期／取貨日期排序
- 備份會包含庫存計算起始日

陳家糖燻滷味 PWA V2

新增功能：
1. 進貨管理：日期、品項、數量、備註，可修改/刪除。
2. 庫存管理：進貨增加、訂單扣庫，負庫存醒目提醒。
3. 庫存異動紀錄：顯示進貨與訂單異動及結餘。
4. 庫存品項管理：可新增、改名、排序、停用、刪除。
5. 訂單扣庫設定：每個訂單品項可自行指定庫存品項與扣庫倍率。
6. 預設新增「白蝦」。醉雞預設不扣庫存，請至「扣庫設定」自行指定。
7. V1 資料庫可直接升級，舊訂單會依升級當下的扣庫設定建立庫存快照。
8. 備份格式已升級為 V2，包含訂單、進貨、庫存品項與扣庫設定。

GitHub Pages 更新方式：
把此資料夾內所有檔案上傳到原 Repository 根目錄，覆蓋同名檔案並 Commit。
建議上傳後等待 1~3 分鐘，再在手機關閉 App/Chrome 後重新開啟。


V2.2 修正：
- 庫存改為依目前『扣庫設定』即時計算，不再依賴訂單建立當下的舊快照。
- 新增訂單品項／庫存品項後，只要儲存扣庫設定，既有與新訂單都會立即依設定重算庫存。
- 庫存異動紀錄同步使用目前扣庫設定重新計算。


V2.4 新增：
- 訂單管理每筆訂單新增「處理完成」按鈕。
- 已處理訂單改為綠色底與綠色側邊標示，並顯示「✓ 已處理」。
- 已處理訂單可按「恢復待處理」切回未處理。
- 處理狀態只作流程辨識，不影響訂單內容與庫存扣除。


V2.4 新增
- 新增訂單每個品項可選「不切 / 切」，預設不切。
- 切法會隨訂單保存，修改訂單時自動帶回。
- 訂單管理與每日統計會顯示每個品項的切法。
- Excel 訂單明細會以「數量（切/不切）」匯出。
- 切法不影響庫存扣除。
